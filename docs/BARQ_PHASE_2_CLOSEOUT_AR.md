# إغلاق المرحلة الثانية — برق BARQ

آخر تحديث: 2026-11-20

## المنجز والمتحقق

- إضافة فحص صحة حي `GET /health/live` لا يعتمد على قاعدة البيانات.
- إضافة فحص جاهزية `GET /health/ready` يتحقق من إعدادات البيئة وينفذ `SELECT 1`.
- اختبارات وحدة لفحوصات الصحة وحالات غياب الإعدادات وفشل اتصال قاعدة البيانات.
- إنشاء قاعدة D1 اختبارية مستقلة باسم `barq-phase2-test-2026-11-20` ومعرّفها `5bfada32-4f9b-4edb-85dd-3b3b30ab73b0`.
- التحقق من اختلاف معرّف قاعدة الاختبار عن قاعدة الإنتاج؛ لم تُستخدم قاعدة الإنتاج في الترحيلات.
- تطبيق ترحيل `0001_recovery_codes.sql` على قاعدة الاختبار المعزولة فقط.
- نجاح اختبار HTTP محلي لنقطتي الصحة باستخدام Worker محلي وبيانات D1 محلية.
- نجاح Backend CI على commit `c6522e926a0762a9aa1426be78abb3d39550fa95`.
- نجاح Backend CI مجددًا على commit `e212094d7199890d330d73559a5192d2f8b8cd42`، بما فيه اختبارات المصادقة وعقد مسارات API والتحقق من عزل إعداد Wrangler.
- نجاح فحص صلاحية الوصول إلى حساب Cloudflare وقراءة قائمة D1 دون إجراء تغييرات.
- تصحيح تقرير توافق Android/API، وتثبيت الفجوات الحقيقية دون الادعاء بأن المسارات غير الموجودة تعمل.
- التحقق محليًا من سلامة ZIP وفهرس الملفات، وصحة YAML لملفي `pubspec.yaml` و`pubspec.lock`، ووجود قفل لكل الاعتماديات المعلنة (13 من 13)، وصحة ملفات XML وFirebase JSON في الفحص السابق.
- التحقق من وجود Gradle wrapper واختبار Flutter وملف CI، وأن `namespace` و`applicationId` كلاهما `com.barq.app`، وأن Release لا يستخدم توقيع Debug. هذه فحوصات بنيوية فقط وليست بديلًا عن تشغيل Flutter أو بناء APK.

## غير المنجز — يمنع إعلان المرحلة مكتملة

1. لم يتوفر Flutter أو Dart في بيئة التنفيذ؛ لذلك لم تُنفذ `flutter pub get` أو `flutter analyze` أو `flutter test` أو بناء APK.
2. لم يُنفذ اختبار حي من تطبيق Android على Worker منشور؛ فحوصات HTTP المنفذة محلية فقط.
3. حزمة Android مصدر منفصل وليست ضمن مستودع GitHub الحالي، ولذلك لم تعمل عليها GitHub Actions بعد.
4. يلزم توحيد والتحقق من هوية الحزمة بين النسخ السابقة والمصدر الحالي قبل أي توزيع.
5. يلزم إعداد توقيع Release آمن بمفتاح يملكه صاحب المشروع؛ لا يستخدم توقيع debug.
6. كشف فحص التوافق الساكن اختلاف مسارات يستدعي المعالجة في مراحل الميزات: الرسائل المؤقتة، رابط الدعوة الخاص، تحويل الصوت إلى نص، ورفع صورة الملف الشخصي. لا تُعد هذه المسارات متحققة وظيفيًا في هذه المرحلة.

## حدود السلامة

- لا دمج لأي PR ولا نشر لأي Worker.
- لا تعديل أو ترحيل لقاعدة بيانات الإنتاج.
- قاعدة الاختبار وحدها استُخدمت في الترحيل البعيد.
- لا تُعلن المرحلة الثانية مكتملة حتى إتمام فحوص Android والاختبار الحي وإغلاق عناصر التوافق أعلاه.
- لا يبدأ العمل في المرحلة الثالثة قبل موافقة المستخدم الصريحة.
