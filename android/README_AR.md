## متطلبات بيئة التطوير
يتطلب هذا المصدر Flutter 3.50 أو أحدث (Dart 3.13 أو أحدث) بسبب حزمة `material_ui` والحزم الحديثة المستخدمة. بعد فك الحزمة شغّل `flutter pub get` لتحديث `pubspec.lock` وملفات الإضافات قبل التحليل والاختبار.

# برق (BARQ) — حزمة مصدر Flutter

هذه حزمة مصدر عمل مبنية على آخر نقطة مصدر متاحة بتاريخ 18 نوفمبر 2026، وليست إصدارًا نهائيًا.

## الموجود في المصدر
- واجهة عربية تحمل اسم «برق».
- ملف شخصي وإعدادات الخصوصية وتفضيلات الإشعارات الموجودة في المصدر.
- تهيئة Firebase Messaging وتسجيل رمز الجهاز عند توفر جلسة.
- المرفقات مع توجيه الملفات حتى 4 ميجابايت عبر Vercel والملفات الأكبر مباشرة إلى Cloudflare Worker لتجاوز سقف حمولة Vercel Functions.
- تحميل الرسائل الخاصة ورسائل المجموعات على صفحات باستخدام cursor، مع دمج الصفحات ومنع تكرار الرسائل.
- مطابقة أرقام جهات الهاتف بعد إذن القراءة، وبدء المطابقة عند فتح تبويب الأشخاص، مع تحديث تلقائي عند عودة التطبيق للواجهة ومهلة دقيقة لتقليل الطلبات المتكررة.
- عرض أعضاء المجموعة ومالكها، مع بقاء صلاحيات الإضافة محكومة بالخادم.
- إلغاء تسجيل رمز FCM عند تسجيل الخروج، وإنشاء قنوات إشعارات Android المتوافقة مع معرفات الخادم.
- REST API: `https://siraj-api-2026.vercel.app`.
- WebSocket: `wss://siraj-api.alhmdanybdhmhmwd.workers.dev/api/realtime`.
- دعم Android 8+ عبر `minSdk = 26`.

## فتح المشروع والبناء لاحقًا
افتح الدفتر `BARQ_Colab_Builder.ipynb` في Google Colab واتبع الخلايا بالترتيب. الدفتر يفحص الاعتماديات ويشغّل التحليل والاختبارات. بناء APK النهائي متوقف افتراضيًا حتى اكتمال جميع الميزات والإصلاحات والاختبارات على جهازين.

## ما لم يكتمل بعد
هذه الحزمة لا تثبت اكتمال المنتج. يلزم استكمال ومراجعة حالات الصور والفيديو، التشفير الطرفي E2E، اختبارات الإشعارات والوسائط والمجموعات، وفحص الاتصال عبر شبكات يمن نت ويمن موبايل وسبأفون وشبكة أخرى دون VPN.

## الميزات الست — تنفيذ أولي في فرع التطوير
- **وضع البرق:** يوقف إرسال المرفقات والوسائط ويُبقي النص.
- **الأجهزة القريبة:** Google Nearby Connections لنقل الرسائل النصية دون إنترنت، مع طابور محلي ومزامنة لاحقة ومعرّفات تمنع التكرار.
- **الرسائل المؤقتة:** مسار D1 مستقل يحذف الرسالة بعد 10 ثوانٍ من أول قراءة؛ لا تدخل Firebase ولا جدول الرسائل العادي.
- **الترجمة:** ML Kit على الجهاز، مع إبقاء النص الأصلي وإظهار الترجمة الاختيارية.
- **تفريغ الصوت:** Cloudflare Workers AI Whisper عند الضغط على زر التحويل؛ يُرسل التسجيل إلى Cloudflare للمعالجة بعد موافقة المستخدم، وحد الملف 8 MB.
- **الدعوات الخاصة:** رمز فريد لكل حساب يمكن مشاركته يدويًا مع أشخاص يختارهم المستخدم؛ لا شارات أو ألقاب أو إطارات أو مكافآت أو دعوات عامة.

هذه الميزات أُضيفت إلى المصدر والـ Worker في فروع GitHub مستقلة وطلبات مراجعة مسودة، ولم تُنشر إلى الإنتاج. الدعوات خاصة فقط، ولا تتضمن عدّادات أو مكافآت أو شارات. رابط الدعوة الحالي يفتح التطبيق إذا كان مثبتًا؛ رابط HTTPS للتثبيت يحتاج نطاقًا رسميًا وصفحة متجر. يلزم تشغيل `flutter pub get` و`flutter analyze` و`flutter test`، واختبارات Worker، ثم اختبار جهازين فعليين قبل اعتبار الميزات مكتملة.

راجع `BARQ_SIX_FEATURES_STATUS.md` لمعرفة تفاصيل التنفيذ والاختبارات المتبقية.

## توافق Firebase
تم تسجيل تطبيق Android في مشروع Firebase المستقل BARQ (`barq-60b76`) بالمعرّف `com.barq.app`، وملف `google-services.json` المرفق يطابق هذا المعرّف. ملف `google-services.json` الموجود إعداد عميل Android وليس مفتاح Admin. لا تضع مفاتيح Admin أو أسرار الخادم في التطبيق.

## تنبيه أمان
خادم API وCloudflare Worker وقاعدة D1 وخدمة تخزين الوسائط تُدار منفصلة عن تطبيق Android. وجود عناوينها في التطبيق لا يعني أن ميزاتها منشورة أو مختبرة بالكامل. لا ترفع أسرار الإنتاج إلى GitHub أو Colab.

## اختيار بيئة الاتصال (الإنتاج أو الاختبار)

أصبحت عناوين API والوسائط والاتصال اللحظي قابلة للتحديد وقت البناء دون تعديل الكود. تبقى عناوين الإنتاج هي الافتراضية، ولا تستخدم عناوين الاختبار إلا بعد تجهيز خادم وقاعدة بيانات اختبار منفصلين.

مثال بناء نسخة اختبار بعد توفير العناوين الصحيحة:

```bash
flutter build apk --debug \
  --dart-define=BARQ_API_BASE=https://PREVIEW_API_HOST \
  --dart-define=BARQ_MEDIA_BASE=https://PREVIEW_MEDIA_HOST \
  --dart-define=BARQ_REALTIME_URL=wss://PREVIEW_REALTIME_HOST/api/realtime
```

لا تضع كلمات مرور أو مفاتيح سرية في `--dart-define`؛ هذه القيم ليست مخزن أسرار. لا توجّه نسخة الاختبار إلى قاعدة الإنتاج. اترك القيم الافتراضية للإصدار الإنتاجي ما لم تُعتمد بيئة أخرى.
